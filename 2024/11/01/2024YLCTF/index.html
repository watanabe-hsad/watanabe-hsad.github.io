sys.schema_table_statistics_with_buffer 是 SQL Server 中的一个系统视图，它提供了有关表和索引的统计信息，包括缓冲区中的数据页

SELECT 
    table_schema,
    table_name,
    last_user_seek,
    last_user_scan,
    last_user_lookup,
    last_user_update,
    user_seeks,
    user_scans,
    user_lookups,
    user_updates,
    buffer_pages,
    buffer_mb
FROM 
    sys.schema_table_statistics_with_buffer
WHERE 
    table_schema = 'dbo'
ORDER BY 
    buffer_mb DESC;
